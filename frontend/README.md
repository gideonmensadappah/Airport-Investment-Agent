# Airport Investment Agent Client

Minimal React, TypeScript, and Vite client.

## Development

```powershell
# Run CI
npm ci

# Run Client Server
npm run dev
```

Open `http://localhost:5173` in the browser.

## Session replay

Set `VITE_LOGROCKET_APP_ID` to the app ID shown under **Settings → Project Setup**
in LogRocket. When it is not set, LogRocket is disabled. Chat questions, analysis
responses, form input, and network bodies are excluded from recordings.

## Production build

```powershell
npm run build
```
